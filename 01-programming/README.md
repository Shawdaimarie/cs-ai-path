# 01 · Programming

**Goal:** Write clean Python, understand core data structures, and reason about algorithmic complexity.
**Time:** ~150 hours

## Why this tier exists

Everything after this assumes you can turn an idea into working code without friction. Data structures and complexity analysis are what separate someone who can code from someone who can engineer.

## Resources, in order

1. **CS50x** (Harvard) — ~70 hours
   Weeks 0–5 are essential. You'll write C before Python; that's deliberate. Understanding memory once makes everything later easier. Do the problem sets — they are the course.

2. **CS50P: Introduction to Programming with Python** (Harvard) — ~30 hours
   Move quickly through what CS50x already covered. Focus on the weeks on exceptions, libraries, unit tests, file I/O, and object-oriented programming.

3. **MIT 6.006: Introduction to Algorithms** (OpenCourseWare) — ~50 hours
   Lectures on sorting, hashing, trees, graph search, shortest paths, and dynamic programming. Do the problem sets for at least the first half.

## Optional

- **Automate the Boring Stuff with Python** — practical scripting if CS50P felt too abstract
- **NeetCode "Blind 75"** — do these for pattern recognition, not to memorize answers. Stop if it starts feeling like a game.

## Checkpoint

Implement from scratch in Python, with tests:

- [ ] A hash map with collision handling
- [ ] A binary search tree with insert, search, and delete
- [ ] Dijkstra's shortest-path algorithm
- [ ] For each: state the time complexity of every operation and explain why

## Capstone

A command-line tool that solves a real problem for *you*. Examples: a file organizer, a budget tracker, a flashcard app, a habit logger. Requirements:

- Reads and writes files
- Has at least one non-trivial data structure at its core
- Has tests
- Has a README that explains what it does and how to run it
- Lives on your GitHub

Real problem, small scope, finished. That's the whole assignment.
