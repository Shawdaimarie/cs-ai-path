# 00 · Prerequisites

**Goal:** Be comfortable in a terminal, use Git without fear, and have the math you'll need for Tier 01.
**Time:** ~30 hours

## Why this tier exists

Almost everyone who abandons a CS path does it here, not in the hard parts — they get stuck on a terminal command or a Git error and lose momentum. Thirty hours now saves hundreds later.

## Resources, in order

1. **The Missing Semester of Your CS Education** (MIT) — ~12 hours
   Lectures 1–6: shell, shell tools, editors, data wrangling, command-line environment, version control.
   Watch, then redo every example yourself. Skip the remaining lectures for now.

2. **Pro Git**, chapters 1–3 (free at git-scm.com/book) — ~8 hours
   Chapter 2 is the one that matters. Do every command as you read.

3. **Khan Academy** — Algebra II and Precalculus — ~10 hours
   Only these units: functions, exponents and logarithms, sequences and series. You need these for algorithm analysis in Tier 01. Take the unit tests; skip anything you pass cold.

## Checkpoint

From an empty directory, using only the terminal:

- [ ] Initialize a Git repository
- [ ] Create a branch and make three commits on it
- [ ] Merge the branch back into `main`
- [ ] Push to a new GitHub repository
- [ ] Do it all in under 10 minutes without looking anything up

If you can, move on. If not, repeat the Pro Git chapters.

## No capstone

This tier is setup, not a project. Your first shipped project comes in Tier 01.
