# Contributing

Thanks for wanting to improve this. The bar is deliberately high — the value of this repo is that it stays small.

## What gets accepted

- **Replacements.** A resource that is clearly better than one currently listed for the same goal. Say why.
- **Gap fills.** A resource covering something a tier's goal requires but no current resource teaches.
- **Corrections.** Dead links, wrong chapter numbers, outdated course names.
- **Checkpoint improvements.** Exercises that test the tier's goal more precisely.

## What gets declined

- Adding a resource without removing one ("also consider…")
- Paid resources where a free one exists, unless the paid one is dramatically better and marked **Paid**
- Anything that requires a specific vendor's platform to complete
- Your own course, book, or product, unless someone else nominates it
- Reordering tiers without a strong argument in the PR description

## How to submit

1. Open an issue first if the change is more than a link fix.
2. One change per pull request.
3. In the PR description, state: what you're changing, what it replaces, and why it's better.

## Style

- Resource names in *italics*, author or institution in parentheses
- No adjectives like "amazing" or "must-read" — the fact that it's listed is the endorsement
- Keep every tier to 3–5 core resources
